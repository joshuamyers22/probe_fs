# Reproducibility package validation

Validated locally on 2026-09-09 on macOS ARM64. The workspace ZIP was extracted
into a new temporary directory, outside the project checkout, with no `.git`,
virtual environment, raw datasets or original results directories. A fresh
environment was installed with `uv sync --locked --all-extras --offline`.
Dependencies came from the local package cache; scientific inputs came entirely
from the bundle or were generated by the smoke test. This was not a test of
dependency downloads on a machine with an empty package cache.

| Check | Result |
| --- | --- |
| Tests in extracted workspace | 114 passed on Python 3.12.11; two existing scikit-learn `n_alphas` deprecation warnings |
| Ruff and whitespace checks | Passed |
| Recorded evidence integrity | All 2,486 members matched their hashes and sizes; 2,182 checkpoint records across seven components |
| Reanalysis without fitting | All seven study summaries and the paired selection-policy statistics matched recorded JSON exactly; plots regenerated |
| Fresh synthetic smoke | Both selection policies and all eight context controls completed; 10,196 model fits |
| Smoke resume | All 10 checkpoint hashes and modification times unchanged |
| Historical source restoration | All seven catalog entries matched every recorded core/build-source hash |
| Historical expanded resume | 240 paired checkpoints unchanged in hash and modification time |
| Historical context-control resume | 960 method checkpoints unchanged in hash and modification time |
| Python distributions | Source distribution and library wheel built successfully from the extracted workspace |
| Distribution contents | Source distribution includes evidence, scripts, documentation, tests and lock; raw data and working result directories excluded |
| Original evidence preservation | All 2,486 bundled evidence files still matched their originals after validation |
| Workspace packaging | Archive and member checksums verified; repeated builds with identical inputs produced identical bytes |

The historical runs used **Python 3.12.14**. The first resume attempt with
3.12.11 correctly failed the run-identity check. Installing the recorded patch
version made both historical resumes pass. Generated `REPLAY.md` instructions now
derive the required Python version from each study's provenance. New runs can use
another supported interpreter, but their provenance differs.

The historical resume checks used isolated restored workspaces and locked
dependencies. They reused checkpoints rather than rerunning the full scientific
grids. Fresh fitting was restricted to the smoke test, which is explicitly
excluded from scientific conclusions. Full-grid cross-platform numerical
replication has not been established by these checks.

The table above records the initial local package validation. During
[PR #1](https://github.com/joshuamyers22/probe_fs/pull/1), Linux CI passed the test
suite and fresh smoke but exposed three revised-study confidence-interval
endpoints differing from macOS by roughly 3e-17. Exact comparison correctly
rejected them. An explicit `--allow-roundoff` mode now logs each accepted finite
float difference (rtol=1e-12, atol=1e-14); integer counts and structure remain
exact. Thirteen added checks cover the observed difference and reject substantive
or structural changes. The updated local suite passes **127 tests**.

CI selects each Python matrix version explicitly, verifies evidence, and runs
smoke and roundoff-aware reanalysis on Python 3.12. It uploads the package and
verification reports. Consult the PR checks for hosted results for the latest
commit; this document does not claim a public release or full-grid refitting.
